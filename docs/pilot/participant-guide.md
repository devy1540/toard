# 파일럿 참여 안내 초안

toard는 여러 AI 코딩 도구의 사용 기록을 모아 API 요율 환산액과 수집 상태를 확인하는 도구입니다. 구독 청구서를 대신 계산하거나 개인의 성과를 평가하려는 목적은 아닙니다.

1. 팀에서 받은 초대 링크로 로그인합니다. 계정과 팀 소속은 관리자가 지정합니다.
2. 설정에서 컴퓨터 연결을 시작합니다. 본문 수집은 끄고, **설치 후 프로젝트를 직접 선택**을 유지합니다.
3. 표시된 설치 명령을 자신의 컴퓨터에서 실행합니다. 명령에 포함된 토큰은 다른 사람이나 이슈에 공유하지 않습니다.
4. 로컬 창에서 업무 프로젝트만 선택합니다. 작업 경로·로그 그룹·미식별 기록의 차이를 확인합니다. 목록에 아직 없다면 도구를 한 번 사용한 후 다시 확인할 수 있습니다.
5. 컴퓨터 연결과 첫 사용량 저장은 별도로 확인합니다. 단순 연결 성공만으로 수집 완료로 보지 않습니다.
6. 일주일 후 주간 보고서와 CSV를 확인합니다. 미확정·이전 계산·수집 대기 항목이 있으면 총액을 실제 비용으로 해석하지 않습니다.

중단하고 싶으면 로컬 범위를 일시 중지하고 담당자에게 알립니다. 이미 서버에 저장된 기록은 범위 변경으로 자동 삭제되지 않습니다. 삭제·보존 정책은 팀에서 정한 절차를 따릅니다.

문제를 공유할 때에는 도구/OS/shim 버전, 발생 단계, 오류 코드와 재현 절차만 먼저 알려주세요. 토큰·비밀번호·대화 본문·개인 프로젝트 경로는 보내지 마세요. 화면 공유가 필요하면 민감정보를 가린 후 별도로 동의해 주세요.
