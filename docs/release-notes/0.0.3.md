# 0.0.3 릴리스 후보

아직 발행하지 않은 후보 변경이다. 실제 배포는 [릴리스 절차](../RELEASE.md)와 [전환 안내](../trust-roadmap-upgrade.md)를 따른다.

- 기본 가입은 invite-only이며 공개 가입은 검증된 OAuth identity로 제한한다. 팀 소속은 관리자가 배정한다.
- 요청 문맥별 요율·캐시·fast 조건을 반영하는 cost-v2, 계산 버전·가격 revision ledger, 추정/미확정 구분을 추가한다. 이전 금액은 새 계산으로 오인하지 않도록 보존한다.
- 실제 사용량 저장과 연결 확인을 구분한다. 사용량은 로컬 SQLite에 commit한 뒤 cursor를 전진시키고 서버 확인 후 정리한다.
- 서버별 도구·프로젝트 범위를 로컬에서 검토한다. 신규 review 설치는 승인 전 전송을 멈추며, 범위 밖 대기 기록을 보존한다.
- 완료된 주의 비용 변화 요인, 개인·권한 있는 팀/조직 보고서, 근거와 수집 상태, CSV 다운로드를 제공한다.
- 정적 제품 미리보기를 복구하고 실제 브라우저·CLI·PostgreSQL·ClickHouse 회귀 검증을 추가한다.

마이그레이션은 1700000054와 1700000055이며 Helm 기준도 55다. 먼저 collection-scope-v1 shim artifact를 게시한 뒤 새 설치 UI를 배포한다. 이미 실행 중인 외부 AI 프로세스는 설정 전환 시 재시작이 필요할 수 있다.

주간 금액은 API 요율 환산액이다. 가격이 없거나 근거가 부족한 모델을 비용 절감으로 해석하지 않는다. 실제 외부 팀 파일럿의 결과는 아직 확보하지 않았다.
