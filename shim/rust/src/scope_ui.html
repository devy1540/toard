포함·제외 모드에서는 프로젝트를 식별하지 못한 기록을 보내지 않습니다. 경로와 로그 그룹은 구분해서 표시합니다. Cursor의 사용량 경로와 대화 기록 그룹은 각각 선택할 수 있습니다.

전송 전 확인

사용량에는 도구·모델·시각·토큰 수·세션 ID·컴퓨터 이름이 포함됩니다. 범위 설정용 경로와 선택 목록은 서버에 추가로 보내지 않습니다. 본문 수집을 켠 경우에는 선택한 기록의 본문도 기존 정책대로 전송합니다. 프로젝트 제한을 사용하면 전역 도구 목록 전송도 중지됩니다. 범위 밖의 사용량 대기 기록은 로컬 보관함에 남습니다.
