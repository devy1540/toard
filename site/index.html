서버 하나와 컴퓨터별 수집기

수집기는 로컬 기록을 읽어 서버로 전송합니다. 서버가 개발자 컴퓨터에 접속할 필요는 없습니다.

1. 서버 설치

Docker Compose로 앱과 PostgreSQL을 실행하고 첫 관리자를 설정합니다.

2. 멤버 초대

관리자가 발급한 초대로 가입합니다. 공개 가입이 필요한 설치는 검증된 OAuth 계정만 허용할 수 있습니다.

3. 컴퓨터 연결

설정의 컴퓨터 연결 안내를 따릅니다. Claude Code·Codex·Gemini·Qwen은 로컬 로그, Cursor는 stop hook으로 사용량을 수집합니다.

설치 전에 알아둘 범위

  • 비용은 API 요율로 계산한 추정액입니다. 구독료·할인·추가 과금을 포함한 청구서 대조 기능은 아직 없습니다.
  • MCP·스킬 활동과 설치 현황은 Claude Code·Codex·Cursor에서 지원합니다. Gemini·Qwen은 이 메타데이터를 아직 지원하지 않습니다.
  • 대화 본문 수집은 별도 설정입니다. 기본 사용량·비용 확인에 본문 수집은 필요하지 않습니다.
  • OTLP 수신과 자동 도구 배포는 실험 기능입니다. 기본 설치에 필요한 기능은 아닙니다.
